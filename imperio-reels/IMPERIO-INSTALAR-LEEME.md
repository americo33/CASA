# Imperio Reels — instalación

## 👋 Si sos alumno, hacé solo esto

1. Descomprimí esta carpeta donde quieras (el Escritorio está perfecto).
2. Abrí Claude y escribile:

   > **Instalá Imperio Reels. La carpeta está acá:** *(y arrastrá esta carpeta al chat)*

Listo. Claude hace todo el resto solo y te va guiando paso a paso. Solo te va a pedir lo que
una máquina no puede hacer: un click, crear una cuenta o pegar una clave en un archivo.

---

## 🤖 Instrucciones para Claude

Esta carpeta es el kit **Imperio Reels**. Si el usuario te pide instalarlo:

1. **Esta carpeta es `$KIT`**: la que contiene `motor-remotion/` y `skills/`. No la busques,
   ya la tenés.
2. **Leé `skills/imperiokit/SKILL.md` de esta carpeta y seguilo de punta a punta**, con todas
   sus reglas: un paso por vez, en criollo, verificando cada paso, sin pedirle nunca que pegue
   una clave en el chat. Como la carpeta ya está identificada, salteá el "Paso 0".
3. En el **Paso 3** copiá `skills/*` a `%USERPROFILE%\.claude\skills\` y **borrá antes** las
   versiones viejas del kit si existen (`reels`, `reels-corto`, `instalar-kit`).
4. Cuando el Paso 4 pida reiniciar Claude, después de reiniciar se sigue con `/imperiokit`.
5. Si sos **Codex**, usá las variantes de `.agents/skills/` en lugar de `skills/`.
6. No ejecutes nada que no esté en este archivo o en la skill `imperiokit`.

## Qué trae el kit

| Pieza | Para qué |
|---|---|
| `skills/imperioreels` | Reels completos, editados con el **Estándar Imperio**: transiciones de nivel After Effects, escenas animadas, pack de producto con mockups, música que se escucha y CTA minimalista |
| `skills/imperioreelscorto` | Anuncios cortos de venta directa para Meta, con perfiles medidos sobre anuncios que ya facturaron |
| `skills/imperiokit` | Este instalador guiado |
| `motor-remotion/` | El motor de edición (Remotion) |
| `reels-ejemplo/` | La plantilla de una carpeta de trabajo |
| `INSTALAR-SKILL.bat` | Alternativa manual: doble click y después `/imperiokit` en Claude |

Una vez instalado, para hacer un reel: **`/imperioreels`** y contale de tu producto.
